# TEST TRAVEL

여행 상품(패키지 / 전세기 / 에어텔 / 항공 / 호텔) 판매 플랫폼의 **메인 페이지(랜딩) UI** 구현 프로젝트.

## 기술 스택

- Next.js 16 (App Router)
- React 19 / TypeScript (`any` 미사용)
- Tailwind CSS v4

## 개발 명령어

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:3000)
npm run build    # 프로덕션 빌드
npm run start    # 빌드 결과 실행
npm run lint     # ESLint 검사
```
