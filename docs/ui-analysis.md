# UI 분석

> 레퍼런스 이미지(`테스트트레벌.jpg`, "TEST TRAVEL" 여행 예약 메인 페이지)를 정밀 판독하여 작성한 구현용 UI 명세서.
> 픽셀 값은 이미지 기준 상대 측정치이며, 확정 불가한 값에는 "약/추정"을 명시한다. 코드·클래스 예시는 담지 않는다.
> 대조 문서: `docs/travelPRD.md`(4·5·6장), `docs/travelROADMAP.md`(Phase 1~7).

---

## 전체 구조

- 페이지는 위에서부터 **유틸리티 바 → 헤더 → 내비게이션 → 히어로 캐러셀 → 프로모션(타임특가) 섹션 → 이벤트/알림 배너 → (이하 하위 섹션·푸터)** 순으로 쌓인다.
- 콘텐츠 최대 폭은 약 1,200~1,280px, 좌우 `mx-auto` 중앙 정렬. PRD 5장(최대폭 1280px)과 일치.
- **히어로 캐러셀만 화면 폭 전체로 bleed**되고, 나머지 섹션은 공통 컨테이너 폭 안에 정렬된다.
- 배경은 기본 흰색(#FFFFFF). 섹션 구분은 배경 톤(옅은 블루틴트/그레이) + 여백으로만 처리하고 굵은 구분선은 쓰지 않는다.
- 세로 리듬: 섹션 간 간격 약 48~64px, 카드 내부 패딩 약 20~24px, 8px 배수 그리드 기조.
- 모서리 곡률(radius)은 세 계열: **pill(완전 둥근) — 검색바·태그 버튼**, **약 16px — 히어로 활성 슬라이드**, **약 8~12px — 카드·이미지·소형 버튼**.

## Header

### 유틸리티 바 (최상단)

- 높이 약 22~24px. 배경은 페이지와 동일(흰색), 아주 옅은 하단 경계.
- 좌측: 파트너/그룹 로고 "KALPAK" — 소형(높이 약 10~12px), 저채도 블루.
- 우측: 텍스트 링크 3개 `로그인` · `멤버실가입` · `고객센터`. 약 12px, 색 `#6B7280`(보조 텍스트), 링크 간 간격 약 16~20px, 구분선 없음.

### 메인 헤더 행

- 높이 약 60~68px. 좌·중·우 3분할.
- **좌측 — 서비스 로고**: 비행기 심볼 마크 + 워드마크 "TEST TRAVEL". 심볼은 단색 채움(fill) 비행기, 색은 브랜드 블루(#2563eb 계열). 워드마크는 볼드, 약 20~22px, 자간 약간 넓음. 심볼과 텍스트 사이 간격 약 8px.
- **중앙 — 검색바(SearchBar)**: 아래 "SearchBar 상세" 참조. 헤더 행 세로 중앙 정렬.
- **우측 — 아이콘 버튼 2개**: `예약확인`(문서+체크 아이콘) · `찜`(빈 하트 아이콘). 각 버튼은 아이콘 위 / 라벨 아래의 **세로 배치**. 아이콘 약 20~22px, 라벨 약 11~12px 색 `#6B7280`. 두 버튼 간 간격 약 20~24px.

### SearchBar 상세

- 형태: 좌우로 긴 **pill**(완전 둥근 모서리). 가로 폭 약 360~420px(반응형으로 확장 여지), 높이 약 40px.
- 배경: 옅은 그레이 채움, 추정 `#F3F4F6`. 테두리 없음(또는 1px 극저채도).
- 내부 좌측: placeholder 텍스트 `여행 상품 검색`, 색 `#9CA3AF`, 약 14px, 좌측 안쪽 여백 약 18~20px.
- 내부 우측: **정사각형에 가까운 파란 제출 버튼**. 배경 브랜드 블루, radius 약 8px(pill 아님), 크기 약 32~34px, 우측 안쪽 여백 약 4px. 내부에 흰색 돋보기(stroke) 아이콘 약 16~18px.
- 상태: 이미지상 비활성(자동완성 드롭다운·검색결과 없음). 입력 필드만 존재.

## Navigation

- 메인 헤더 아래 별도 행. 높이 약 44~48px.
- **좌측 클러스터**: 
  - 햄버거(3줄, stroke) 아이콘이 **얇은 테두리 박스**(약 32×32px, radius 약 6~8px) 안에 들어 있음. 전체 카테고리(GNB) 토글용.
  - 이어서 1차 메뉴 텍스트 링크가 가로로 나열: `THE 팩` · `패키지여행` · `전세기` · `에어텔` · `항공 ✈️` · `호텔 🏨`.
  - 링크는 약 14~15px, 기본색 `#374151`(본문), 링크 간 간격 약 20~24px.
  - 일부 항목 끝에 이모지(✈️ 🏨)가 텍스트로 붙는다(아이콘 컴포넌트가 아니라 문자).
- **우측 클러스터**: `기획전` · `이벤트` 텍스트 링크 2개. 좌측 클러스터와 같은 타이포, 우측 정렬.
- 활성/hover 표시는 이미지에서 뚜렷하지 않음 — 구현 시 색 변화(브랜드 블루) 정도로 최소 처리.

## Hero

- **레이아웃**: 화면 폭 전체 bleed. 가운데에 활성 슬라이드, 좌우로 이전/다음 슬라이드의 가장자리가 미리보기로 노출되는 **중앙 확대(center-mode) 캐러셀**.
- **활성 슬라이드**: 가로:세로 비율 약 21:9(와이드), 좌우 폭은 콘텐츠 컨테이너와 유사(약 1,180~1,280px), 모서리 radius 약 16px. 높이 약 360~400px(추정).
- **좌우 미리보기 슬라이드**: 활성 슬라이드 양옆으로 약 120~180px씩 보임. 밝기를 낮춘(딤) 처리, opacity 약 0.6~0.7. 활성 슬라이드와 미리보기 사이 간격 약 12~16px.
- **오버레이 텍스트**: 활성 슬라이드 중앙. 
  - 윗줄(수식어): 약 14~16px, 흰색, 일반 굵기. 예 "황금 가을에 만나는".
  - 아랫줄(제목): 약 28~34px, 흰색, 볼드. 예 "일본의 숨은 아지트".
  - 두 줄 사이 간격 약 8~12px. 가독성 위해 이미지가 어두운 편(자연광 사진) — 별도 그라데이션 판은 뚜렷하지 않으나 텍스트에 약한 그림자 가능.
- **히어로 컨트롤 바**: 활성 슬라이드 하단 중앙에 가로 배치. 반투명 어두운 pill/바 위에 흰색 요소.
  - 순서: `chevron-left` → `현재/전체` 카운터 텍스트(예 "4 / 16", 약 12~13px 흰색) → `chevron-right` → `일시정지(pause)` 아이콘 → `그리드(전체 썸네일 보기)` 아이콘.
  - 아이콘 약 14~16px, 요소 간 간격 약 10~14px. 컨트롤 바는 슬라이드 하단에서 약 12~16px 띄움.
- 자동재생 상태(일시정지 아이콘 노출 = 재생 중)로 추정.

## Product Section (타임특가 / 마진포기 타임어택)

### 섹션 헤더

- 텍스트: `특가 종료 임박! ⚡ 마진포기 타임어택 ⏰`. 약 18~20px, 볼드, 색 `#111827`(제목).
- 문장 안 이모지(⚡ ⏰)는 아이콘이 아니라 문자. 섹션 상단 여백 약 40~48px.

### 타임특가 카드 (가로형, 1개 노출 + 캐러셀 점)

- 카드 폭 = 콘텐츠 컨테이너 폭. 얇은 테두리(`#E5E7EB`) + 약한 그림자, radius 약 12px. 내부 패딩 약 20~24px.
- **좌측 — 썸네일 이미지**: 카드 높이에 꽉 차는 직사각형, 가로:세로 약 16:10, radius 약 8px, 폭은 카드의 약 38~42%.
- **우측 — 콘텐츠 영역** (세로 스택, 항목 간 간격 약 8~10px):
  1. **라벨 행**: `대만`(국가, 무배경 텍스트) + 항공사 마크(작은 사각 로고, 약 16×16px) + `대한항공`(항공사명, 무배경 텍스트). 약 12~13px, 색 `#6B7280`.
  2. **상품명**: `[마진포기] 대만 추석 전세기 4일`. 약 16~17px, 볼드, 색 `#111827`.
  3. **해시태그 행**: `#선착순 10명 초특가 #대한항공 #단1회 #대만패키지`. 약 12~13px, 색 `#9CA3AF`, 태그 간 공백 약 6~8px. 무배경.
  4. **가격 행**: 원가 `2,099,000원`(취소선, 약 12~13px, 색 `#9CA3AF`) → 판매가 `1,499,000원~`(약 18~20px, 볼드, 색 `#111827`). 이미지상 판매가에 강조 레드는 쓰이지 않음(무채색). 
     - 우측 끝: `자세히보기` 버튼 — 아웃라인형(투명 배경 + 1px 테두리 `#E5E7EB` 또는 블루), radius 약 8px, 패딩 약 8×14px, 약 13px.
  5. **카운트다운 바**: 카드 하단 폭 전체. 배경 옅은 블루틴트(추정 `#E8EDFB`), 높이 약 40px, radius 약 8px. 중앙 정렬 텍스트 `3일 00 : 56 : 25` — 숫자 볼드, 콜론은 여유 간격, 색은 어두운 블루/`#111827`.
- **캐러셀 페이지네이션**: 카드 아래 중앙에 점(dot) 2개. 활성 점은 길쭉한(pill) 형태 + 진한 색, 비활성은 작은 원 + 옅은 회색. 점 지름 약 6~8px.

## Notification Section (이벤트/알림 배너)

- 위치: 타임특가 캐러셀 아래. 폭 = 콘텐츠 컨테이너.
- 형태: 가로로 긴 배너 바. 배경 옅은 블루틴트(추정 `#F2F5FB` ~ `#EEF2FB`), radius 약 10~12px, 높이 약 56~64px, 내부 좌우 패딩 약 20~24px.
- 구성(좌 → 우):
  - 좌측: 소형 아이콘(약 20px, 알림/벨 또는 쿠폰 계열) + 볼드 문구 `가격혜택찬스! 선착순 타임특가 알림신청` (약 14~15px, 색 `#111827`).
  - 중앙: 설명 문구 `멤버십 가입 후 마케팅 정보 수신에 동의하시면 특가상품 오픈 정보를 알려드려요!` (약 13px, 색 `#6B7280`).
  - 우측: `바로 신청하기 >` — 텍스트 링크 + 오른쪽 chevron, 약 13px, 브랜드 블루.

## Responsive

- 이미지는 데스크톱(약 1,440px 뷰포트 기준, 콘텐츠 1,200~1,280px) 한 장뿐이므로 모바일/태블릿은 PRD 6장 규칙으로 보완한다.
- **데스크톱(≥1024px)**: 위 명세대로 3분할 헤더, 가로 내비, 히어로 center-mode, 타임특가 가로형 카드.
- **태블릿(약 768~1023px, 추정)**: 헤더 검색바 폭 축소, 내비 항목 간격 축소 또는 일부 접힘, 히어로 좌우 미리보기 폭 축소, 타임특가 카드 이미지 비율 유지하되 폭 축소.
- **모바일(<768px, 추정)**: 
  - 헤더 = 로고 + 아이콘, 검색바는 아래 줄로 분리되거나 아이콘 토글.
  - 내비는 햄버거(GNB) 안으로 수납, 1차 메뉴 텍스트 링크는 숨김.
  - 히어로는 미리보기 없이 1장 풀폭, radius 축소(약 12px), 오버레이 제목 약 22~24px.
  - 타임특가 카드는 세로 스택(이미지 위 / 콘텐츠 아래), 카운트다운 바는 폭 전체 유지.
  - 알림 배너는 세로 스택(문구 → 버튼).
- 좌우 최소 여백 16px는 전 구간 유지(공통 Container 규칙).
- 가로 스크롤 절대 금지(`overflow-x: hidden`).

### 타이포그래피 (추정 px)

- 워드마크 로고: 약 20~22px / 볼드
- 섹션 헤더: 약 18~20px / 볼드
- 상품명: 약 16~17px / 볼드
- 판매가: 약 18~20px / 볼드
- 내비 링크: 약 14~15px / 레귤러
- 검색 placeholder·본문: 약 14px / 레귤러
- 라벨·해시태그·카운터·유틸 링크: 약 11~13px / 레귤러
- 폰트: 시스템 폰트 스택(웹폰트 미사용).

### 간격·곡률·그림자

- 간격 그리드: 8px 배수. 섹션 간 약 48~64px, 카드 패딩 약 20~24px.
- radius: pill(9999px) / 약 16px(히어로) / 약 8~12px(카드·버튼·이미지) / 약 6~8px(햄버거 박스).
- 그림자: 카드 약한 그림자(shadow-sm ~ shadow-md 수준), 히어로/컨트롤은 그림자보다 딤·반투명으로 처리.

| 재생(PlayIcon) | fill | 약 14~16px | 히어로 일시정지 상태(짝 아이콘) |
| 그리드 2×2(GridIcon) | stroke ≈1.75 또는 fill | 약 14~16px | 히어로 전체 썸네일 보기 |
| 알림/벨(BellIcon) | stroke ≈1.75 | 약 20px | 이벤트/알림 배너 |
| 햄버거 3줄(MenuIcon) | stroke ≈1.75 | 약 18~20px | 내비 GNB 토글 |

- 이모지(✈️ 🏨 ⚡ ⏰)는 아이콘 컴포넌트로 만들지 않고 **텍스트 문자**로 처리한다.
- 항공사 로고 마크(타임특가 카드의 소형 사각 로고)는 저작권 이슈로 이번 범위 제외 — 중립 도형/텍스트로 대체.
- 공통 규칙: `viewBox="0 0 24 24"`, `size` 기본 24, 색은 `currentColor` 상속. stroke 계열은 `stroke-width` 약 1.75 + 둥근 캡/조인. `title` 미전달 시 장식용(`aria-hidden`).

### Badge 수치

- 이미지 기준 **무배경 텍스트 라벨**(칩/알약 아님)이 기본. 국가명("대만"), 항공사명("대한항공"), 해시태그가 해당.
- 텍스트 크기 약 12~13px.
- 국가·항공사 라벨: 색 `#6B7280`(Sub).
- 해시태그: 색 `#9CA3AF`(Muted), 태그 간 공백 약 6~8px.
- 강조가 필요한 국가 라벨 변형은 브랜드 블루 + medium 굵기(선택적).
- ROADMAP 대응을 위한 칩형(neutral) 변형: 옅은 배경(`#F9FAFB`) + 1px 테두리(`#E5E7EB`) + radius 약 6px + 패딩 약 2×8px + 약 12px. (이미지에는 없지만 병행 제공)

### IconButton 수치

- 헤더 우측(예약확인/찜): 아이콘 위 + 라벨 아래 **세로 배치**. 아이콘 약 20~22px, 라벨 약 11~12px 색 `#6B7280`, 아이콘·라벨 간 간격 약 2~4px.
- 히어로 컨트롤: 라벨 없는 **아이콘 전용**. 아이콘 약 14~16px, 흰색.
- 터치 타깃 최소 약 44×44px 확보(시각 아이콘이 작아도 히트 영역 확대).
- 포커스: 키보드 포커스 시 브랜드 블루 포커스 링. hover 시 브랜드 블루로 색 변화.
- 라벨 위치 3종 지원 필요: 우측(right) / 하단(bottom) / 숨김(hidden, `aria-label` 필수).

### SearchBar 수치

- pill 컨테이너: 높이 약 40px, 배경 `#F3F4F6`(추정), radius 9999px, 좌측 안쪽 여백 약 18~20px, 우측 안쪽 여백 약 4px.
- 입력: 투명 배경, 텍스트 색 `#374151`, placeholder `여행 상품 검색` 색 `#9CA3AF`, 약 14px. `aria-label` 또는 sr-only `<label>` 필요.
- 제출 버튼: 배경 브랜드 블루, radius 약 8px(pill 아님), 크기 약 32~34px, 내부 흰색 돋보기 약 16~18px. `aria-label="검색"`.
- 동작: submit 시 `preventDefault` — 검색 실행·자동완성·라우팅 없음. 입력값 외부 전달 없음.

### (4) 디자인 토큰 vs PRD 5장 일치 여부 및 차이점

**일치**

- 콘텐츠 최대 폭 1,200~1,280px 중앙 정렬.
- Primary 브랜드 블루(#2563EB 계열), Strong `#111827`, Body `#374151`, Muted `#9CA3AF`, Subtle `#F9FAFB`, Line `#E5E7EB`.
- 시스템 폰트 스택, 8px 배수 간격, 히어로만 full-bleed.

**차이점 (PRD 대비 보완 필요)**

1. **Sale/Point 레드 미표기**: 이미지의 할인가·타임특가는 무채색(`#111827`)으로 표기됨. → 사용자 확정: **PRD 우선** — `--color-sale`(#e11d48)은 유지하고 Phase 5 할인가·타임특가 강조에 사용. 이미지의 무채색 표기는 채택하지 않음.
2. **Sub 텍스트 계층 부재**: 유틸 링크·라벨·배너 설명에 `#6B7280`이 쓰이나 PRD 토큰에 없음. → `--color-sub: #6B7280` 추가.
3. **입력 배경 톤 부재**: 검색바 pill의 `#F3F4F6`이 토큰화되어 있지 않음. → `--color-field: #F3F4F6` 추가.
4. **알림 배너 블루틴트 부재**: 배너 배경 `#EEF2FB`(카운트다운은 약간 진한 `#E8EDFB`)이 토큰에 없음. → `--color-notice: #EEF2FB` 추가(카운트다운은 별도 근사).
5. **pill(9999px) radius 다수 사용**: 검색바·태그 버튼·활성 페이지네이션 점. PRD의 rounded-xl/2xl 외에 pill 규칙을 명시적으로 운용.
