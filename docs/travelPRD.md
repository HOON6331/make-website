# TEST TRAVEL 메인 페이지 PRD (Product Requirements Document)

## 1. 개요

### 1.1 목적

여행 상품(패키지/전세기/에어텔/항공/호텔)을 판매하는 여행 플랫폼의 **메인 페이지(랜딩)** UI를 구현한다.
첨부 디자인(`c:\Users\14ZB90Q\Downloads\테스트트레벌.jpg`)을 기준으로 깔끔하고 세련된 화면을 만든다.

### 1.2 범위

- **이번 작업 범위**: 메인 페이지 **화면(UI)만** 구현
- 로그인, 검색, 예약, 필터 등 **모든 기능은 비활성(정적 목업)** 으로 처리
- **예외적으로 동작해야 하는 기능**: 메인 히어로(광고) 캐러셀
  - 마우스 호버 효과 적용
  - **3초마다 자동으로 다음 나라 이미지로 전환**
- 상세 페이지, 목록 페이지, API 연동, 백엔드는 범위에서 제외

### 1.3 대상 사용자

- 여행 상품을 탐색하려는 일반 소비자 (데스크톱 우선, 모바일 대응 필수)

## 4. 영역별 상세 요구사항

### (A) 상단 유틸리티 바

- 배경: 흰색 / 얇은 하단 보더
- 좌측: 브랜드 워드마크 텍스트 `KALPAK` (작게, 회색)
- 우측: 텍스트 링크 3개 — `로그인` / `멤버십가입` / `고객센터`
- 링크는 `<a>` 또는 `<button>` 형태이나 클릭 시 **동작 없음**(`href="#"` 또는 `type="button"` + no-op)
- 모바일: 유틸리티 바는 숨기거나 축소

### (B) 헤더 (Header)

- 좌측: 로고 = 비행기 형태 인라인 SVG 아이콘 + `TEST TRAVEL` 텍스트 (굵게)
- 중앙: **검색바**
  - 넓은 pill 형태 입력창, placeholder `여행 상품 검색`
  - 우측 끝에 돋보기 아이콘 버튼
  - **입력은 가능하나 검색 실행/자동완성 없음** (submit 시 preventDefault)
- 우측: 아이콘 + 라벨 2개
  - `예약확인` (문서/체크 아이콘)
  - `찜` (하트 아이콘)
- 스크롤 시 상단 고정(sticky) 여부: **고정하지 않음** (단순 정적 배치, 선택적 개선 항목)
- 모바일: 로고 / 검색 아이콘 / 햄버거로 축약, 검색바는 아래 줄로 내리거나 아이콘 토글

### (C) 글로벌 내비게이션 (GNB)

- 좌측: 햄버거(전체 카테고리) 버튼 — 클릭 시 **동작 없음**
- 메뉴 항목(좌측 정렬):
  - `THE 팩`
  - `패키지여행`
  - `전세기`
  - `에어텔`
  - `항공 ✈️`
  - `호텔 🏨`
- 우측 정렬 보조 메뉴:
  - `기획전`
  - `이벤트`
- hover 시 텍스트 컬러 강조 / 밑줄 정도의 인터랙션만
- 모든 메뉴는 링크 형태이나 **페이지 이동 없음**
- 모바일: 가로 스크롤 되는 탭 형태 또는 햄버거 내부로 수납

### (D) 메인 히어로 캐러셀 (Hero Carousel) — ★ 핵심 기능

#### 4.D.1 목적

나라별 여행 광고 이미지를 큰 배너로 노출하고, 자동으로 순환시켜 다양한 목적지를 홍보한다.

#### 4.D.2 시각 구조 (coverflow 스타일)

- 화면 중앙에 **현재 활성 슬라이드**를 크게 배치 (라운드 코너, 그림자)
- 중앙 슬라이드의 **좌/우 양옆**으로 이전/다음 슬라이드가 **일부만 보이도록** 배치
  - 양옆 슬라이드는 살짝 축소 + 투명도(예: opacity 60~70%) 처리
- 활성 슬라이드 위에 카피 텍스트 오버레이:
  - 소제목 (예: `황금 가을에 만나는`)
  - 큰 제목 (예: `일본의 숨은 아지트`)
  - 텍스트 가독성을 위해 이미지 위 그라데이션/딤 처리
- 하단 중앙 컨트롤 바:
  - `이전(<)` 버튼
  - `현재/전체` 인디케이터 (예: `4 / 16`)
  - `다음(>)` 버튼
  - `재생/일시정지` 토글 버튼
  - `전체 보기(그리드)` 버튼 — **동작 없음(아이콘만)**

#### 4.D.3 데이터 모델 (정적 목업)

슬라이드 배열을 상수로 정의한다. 예시 스키마:

```ts
// 나라별 히어로 슬라이드 데이터 타입
interface HeroSlide {
  id: number; // 고유 id
  country: string; // 나라명 (예: "일본")
  subtitle: string; // 상단 소제목
  title: string; // 메인 카피
  imageUrl: string; // 광고 이미지 경로 (public/images 하위)
  alt: string; // 대체 텍스트
}
```

- 총 슬라이드 수: 디자인의 `4 / 16` 표기를 반영해 **16개 목표**
  - 초기 구현은 **6~8개**로 시작하고 이미지 확보에 따라 확장 (인디케이터 분모는 배열 길이로 자동 계산)
- 이미지는 `public/images/hero/` 하위에 배치, `next/image` 사용
- 이미지 미확보 시 임시로 단색/그라데이션 + 나라명 텍스트 플레이스홀더 허용

#### 4.D.4 동작 요구사항 (functional)

| 항목             | 요구사항                                                                                                                                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 자동 전환        | 활성 슬라이드가 **3초(3000ms)** 후 자동으로 **다음 나라 슬라이드**로 이동                                                                                        |
| 순환             | 마지막 슬라이드 다음은 첫 슬라이드로 무한 순환 (loop)                                                                                                            |
| 전환 애니메이션  | 슬라이드 이동 시 부드러운 트랜지션(약 400~600ms, ease-in-out)                                                                                                    |
| 호버 효과        | 활성 슬라이드에 마우스 오버 시: 살짝 확대(scale) + 그림자 강화 등 시각 효과                                                                                      |
| 호버 시 자동재생 | 마우스가 캐러셀 위에 있는 동안 **자동 전환 일시정지**, 벗어나면 재개 (권장 UX)                                                                                   |
| 수동 조작        | 이전/다음 버튼 클릭 시 해당 방향으로 1칸 이동, 이동 후 자동 타이머 리셋                                                                                          |
| 재생/일시정지    | 토글 버튼으로 자동 전환 on/off, 상태에 따라 아이콘 변경                                                                                                          |
| 인디케이터       | `현재 index+1 / 전체 개수` 실시간 표시                                                                                                                           |
| 접근성           | 캐러셀 영역 `aria-roledescription="carousel"`, 버튼 `aria-label` 지정, 자동재생 중 `prefers-reduced-motion` 존중(모션 최소화 시 자동전환/애니메이션 비활성 고려) |
| 정리(cleanup)    | 컴포넌트 언마운트 시 `setInterval`/`setTimeout` 반드시 해제 (메모리 누수 방지)                                                                                   |

#### 4.D.5 구현 힌트

- `useState`로 `activeIndex`, `isPlaying`, `isHovered` 관리
- `useEffect` + `setInterval`(또는 재귀 `setTimeout`)로 3초 타이머 구성
  - 의존성: `activeIndex`, `isPlaying`, `isHovered`
  - `isPlaying === false` 또는 `isHovered === true`면 타이머 미가동
- 좌우 미리보기는 `activeIndex` 기준 `prev = (i-1+len)%len`, `next = (i+1)%len` 계산
- 트랜지션은 Tailwind `transition-transform duration-500 ease-in-out` + `translate-x` 또는 opacity/scale 조합

### (E) 타임특가 프로모션 섹션

- 섹션 제목: `특가 종료 임박! ⚡ 마진포기 타임어택 ⏰`
- 상품 카드(1개, 가로형):
  - 좌측: 상품 이미지 (라운드)
  - 우측 정보 영역:
    - 나라 뱃지 + 항공사 (예: `대만` · `대한항공`)
    - 상품명 (예: `[마진포기] 대만 추석 전세기 4일`)
    - 해시태그 목록 (예: `#선착순 10명 초특가` `#대한항공` `#단1회` `#대만패키지`)
    - 가격: 원가(취소선, 회색) + 할인가(강조, 큰 글씨) + `원~`
      - 예: ~~2,099,000원~~ **1,499,000원~**
    - `자세히보기` 버튼 (아웃라인) — **동작 없음**
    - 하단 카운트다운 바: `3일 00 : 56 : 25` 형태
      - **표시는 정적(고정 텍스트) 또는 단순 감소 타이머 중 택1** (기본: 정적 목업, 선택적으로 1초 감소 구현)
- 카드 하단: 캐러셀 페이지 도트 인디케이터 (2개, 정적)
- 모바일: 이미지 상단 / 정보 하단으로 세로 스택

### (F) 알림 신청 배너

- 옅은 배경색의 가로 배너
- 좌측 아이콘 + 제목 `가격혜택찬스! 선착순 타임특가 알림신청`
- 본문 `멤버십 가입 후 마케팅 정보 수신에 동의하시면 특가상품 오픈 정보를 알려드려요!`
- 우측 `바로 신청하기 >` 링크 — **동작 없음**
- 모바일: 세로 정렬

### (G) 푸터 (Footer)

- 디자인 이미지에는 미포함이나, 페이지 완성도를 위해 **간단한 기본 푸터** 추가
- 회사 정보 더미 텍스트, 이용약관/개인정보처리방침(링크 비활성), 카피라이트
- 과하지 않게 최소 구성

## 9. 접근성 & 품질 기준

- 모든 이미지에 의미 있는 `alt` 제공 (장식 이미지는 `alt=""`)
- 인터랙티브 요소는 `<button>`/`<a>` 사용, 키보드 포커스 링 유지
- 캐러셀: `aria-label`, 자동 전환 일시정지 수단 제공(재생/정지 버튼), `prefers-reduced-motion` 대응
- 색 대비: 텍스트/배경 WCAG AA 이상 목표 (특히 히어로 오버레이 텍스트)
- Lighthouse 기준 접근성/베스트프랙티스 90점 이상 지향
- `any` 타입 미사용, ESLint/TypeScript 에러 0
- 콘솔 에러/경고 0
